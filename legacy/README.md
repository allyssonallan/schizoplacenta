# Legacy scripts (first submission)

These scripts produced the outcome analyses of the first submitted version. They fit `~ factor(mean score)` per domain and report `coef = 2`, which is a contrast between score levels rather than DD vs TD, and they select genes from the intercept column of `decideTests`. They are kept unchanged for provenance and are **superseded** by `R/00–04` and `run_all.R`. Do not use them for new results.
